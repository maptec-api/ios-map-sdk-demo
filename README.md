# MaptecMaps Example

This is the public MaptecMaps iOS example app. It integrates MaptecMaps through the bundled XCFrameworks in `Frameworks/`.

## Build

```sh
pod install
open MaptecMapsExample.xcworkspace
```

Select the `MaptecMapsExample` scheme and run the app.

## API key

This public example does not contain a default API key. Configure your own key
through the authentication screen before using map services.
